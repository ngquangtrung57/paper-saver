1

Create Notion Integration

Go to notion.so/my-integrations and create a new integration

2

Get Integration Token

Copy the "Internal Integration Token" — it starts with ntn_ or secret_

3

Create a Project

Use + New Project above to create a project. You can create a new Notion database or link an existing one.

4

Share with Integration

Open any Notion page, click "..." → "Add connections" → select your integration
